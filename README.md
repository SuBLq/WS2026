# Whiteout Survival — мобильный справочник · v3 SuBL

Веб-версия гайдов Whiteout Survival, оптимизированная прежде всего для смартфона.




## v10

- обновлённый гайд Рудника Ледяного Огня;
- Калькулятор технологий v0.4: профиль → цель → автоматический путь;
- управление технологиями слайдерами;
- кнопка ряда заполняет все предыдущие ряды ветки до MAX;
- полностью изученные технологии исключаются из выбора цели;
- локальная экономика 588/588 уровней; сетевые данные для расчёта не используются.


## v14

- список целей разделён на «Ближайшие — можно изучать сейчас» и «Дальше по дереву»;
- дальние технологии сортируются по длине недостающего пути, поэтому ближайшие будущие цели находятся выше;
- доступность пересчитывается по текущим технологиям и уровню Исследовательского центра.


## Калькулятор технологий v0.7

- удалён блок «до первой Битвы VI»;
- цели сгруппированы по доступности, тиру и структурным блокам дерева;
- итог перенесён над маршрутом;
- маршрут разделён на выбранную цель и необходимые технологии;
- добавлены кнопки MAX / MIN / Очистить;
- для каждого улучшения показываются текущее и базовое время, а также ресурсы.


## Изменения v14

- слайдеры текущих и промежуточных технологий обновляют состояние и итоговые суммы во время движения;
- каскадная перестройка списка закрепляется при завершении жеста, чтобы ползунок не дёргался на смартфоне;
- добавлена одноразовая памятка первого входа и кнопка `?` для повторного открытия.

## Калькулятор технологий v0.9 / сайт v15

- выбор технологии теперь открывает предпросмотр и не меняет маршрут автоматически;
- предпросмотр показывает цену самой цели и цену обязательных технологий;
- цель попадает в расчёт только после кнопки «Добавить в план расчётов»;
- блок обязательных технологий визуально объединён с их списком;
- «Очистить технологии» в профиле работает через надёжное двойное нажатие и не сбрасывает Исследовательский центр или скорость исследований.
