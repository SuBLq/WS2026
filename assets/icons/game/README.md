# Игровые пиктограммы

Папка содержит нормализованные PNG 128×128 на прозрачном фоне. Имена файлов семантические и используются `assets/js/game-icons.js`.

## Важные соответствия

- `essence-stone.png` — Камень Эссенции (серый камень с красным молотом), относится к снаряжению героев.
- `mithril.png` — Мифрил (фиолетовый кристалл), относится к позднему усилению снаряжения героев.
- `hardened-alloy.png` — Закалённый сплав (серебристый слиток), относится к снаряжению губернатора.
- `talisman.png` / `charm-guide.png` — талисманы губернатора / Charm Guide.
- `charm-design.png` — Charm Design (пергамент с красной геометрической схемой).

`rare-crystal.png` оставлен только как legacy-алиас исходного пакета и не должен использоваться в новых правилах.


## Специальные привязки событий
- `bear-hunt.png` — «Охота на медведя». Используется на главной, в заголовке гайда и перекрёстных ссылках.
- `snowbusters.png` — «Снегоуборщики», пиктограмма топлива из угля. Используется на главной, в заголовке гайда и перекрёстных ссылках.
## Оптимизация для production

Все рабочие пиктограммы в этой папке приведены к PNG RGBA 128×128. Это соответствует фактическому размеру отображения на главной, в заголовках гайдов и перекрёстных ссылках, сохраняя прозрачность и не перегружая мобильную загрузку. Типичный размер файла — примерно 15–35 КБ. Мастер-файлы 1254×1254 в production-папке не хранятся.
