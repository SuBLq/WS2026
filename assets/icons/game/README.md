# Игровые пиктограммы

Папка содержит 128×128 PNG с прозрачным фоном и короткими семантическими именами.

Пиктограммы подключаются автоматически через `assets/js/game-icons.js`: на главной — в карточках гайдов и калькуляторов; внутри гайдов — в шапке, у релевантных H2 и ключевых информационных блоков; также в связанных материалах и результатах поиска.

Система намеренно не ставит значок в каждый абзац: маркеры используются только там, где они ускоряют сканирование страницы.
